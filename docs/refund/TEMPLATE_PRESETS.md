# Refund Workflow Template Presets

## TC-810 intake
Taxpayer; tax year; return reference; exact TC; responsibility/action context; observation source/date; notice; evidence; authorization; practitioner notes.

## TC-570 intake
Taxpayer; tax year; exact TC sequence; adjacent transactions; notice; balance/refund information; source date; supporting evidence; practitioner notes.

## Hold review
Source verified; current procedure identified; notice reviewed; return reviewed; evidence complete; client communication approved; remedy lane selected; reviewer assigned.

## Follow-up
Next review date; owner; source to recheck; permitted cadence; stop condition; escalation condition.

## Closure
Final authoritative evidence; outcome; client communication; remaining balance/status; unresolved issues; closure reason; approver.
