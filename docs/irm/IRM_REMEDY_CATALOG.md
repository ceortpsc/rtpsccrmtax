# IRM Remedy Navigator Catalog

Controlled index only. Always verify the current Internal Revenue Manual and applicable IRS instructions before acting.

## Remedy families

### Notice response
Use when an official notice requests information or action.
Evidence: notice, deadline, requested documents, authorization.
Gate: practitioner review.

### Return correction / amendment review
Use when facts support a correction and applicable filing rules permit it.
Evidence: original return, corrected facts, supporting records, calculation, and applicable amendment mechanism.
Gate: preparer plus reviewer.

### Refund trace review
Use when official information indicates a refund was issued but the taxpayer did not receive it.
Evidence: issuance evidence, filing status, payment method, and financial-institution information where available.
Gate: determine whether the applicable IRS trace process/form is required.

### Identity-verification review
Use when the IRS requests identity verification or identity theft is suspected.
Evidence: official notice, verification status, and authorization.
Gate: do not bypass IRS verification.

### TAS eligibility review
Use only when facts potentially meet current TAS criteria.
Evidence: chronology, prior contacts, notices, hardship/systemic issue facts, and authorization.
Gate: human eligibility review against current TAS procedure.

### Practitioner monitor
Use when no immediate corrective action is supported.
Evidence: last verified status, next review date, source, and procedure version.

## Source governance

Every catalog entry requires official source reference, IRM section where applicable, effective date, last reviewed date, reviewer, superseded version, and applicability notes. The application blocks publication of stale procedures as current.
